## About

I am a software developer specializing in backend development with **C# and .NET**. My work and learning
focus on API design, system integration, authentication and authorization, data consistency, and software
architecture that remains understandable as applications grow.

I also explore **FinTech and digital financial systems**, alongside applied AI topics such as LLM integration,
retrieval-augmented generation (RAG), agentic workflows, and intelligent automation. These are active areas of
learning and experimentation rather than claims of research or production expertise.
